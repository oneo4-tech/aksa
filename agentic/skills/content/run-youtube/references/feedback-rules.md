# Owner feedback rules

Every common rule the owner gave in YouTube reviews, traced to the pipeline step that applies it and what enforces it. Source: the `YouTube: owner` comments on content issue #38 (Spot the Bug long-form) and its Shorts #39 and #40. `youtube-producer` reads this file at the start of every run and checks each row of the current stage before asking for a gate; each specialist applies its step's rows.

Enforced by: **check**, a script refuses the output (exit 3 or 2) and a test covers it; **checklist**, a person or the producer judges it against the named list, with the style guide section the specialist reads. The style guide is the channel's `style-guide.md`; `channel.yaml` holds the machine values.

## Adding a row

- Every owner review comment on a video is a common rule, unless the owner says it holds for that video only (row 38, D-049), and becomes a row: the feedback, the rule, the step, and how it is enforced.
- The producer files the row and the component change it needs in the retrospective (workflow step 8) as a work request; this file and the components change only through the factory (D-038).
- A rule replaced by a later review keeps its row, naming the newer rule, as rows 15 and 26 do.
